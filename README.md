# Rill

Native, configurable desktop bar. Apple Silicon, macOS 14+.

```sh
brew install --cask AleckAstan/rill/rill
rillctl init
open -a Rill
```

Locally signed, not notarized. If macOS blocks opening, use System Settings > Privacy & Security > Open Anyway.

[Documentation and DMG](https://github.com/AleckAstan/Rill)
